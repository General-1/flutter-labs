# Flutter Labs

Mobile application programming labs, built with Flutter in Android Studio.

This branch holds **lab 4** only. Each lab has its own branch:
`lab1`, `lab2`, `lab3`, `lab4`.

| Lab | Folder | Description |
|-----|--------|-------------|
| 4 | [lab4_appointment](lab4_appointment/) | Lab 3 app with REST services, JSON serialization and Clean Architecture |

## Running the lab

Open `lab4_appointment` in Android Studio (File → Open), or from a terminal:

```bash
cd lab4_appointment
flutter pub get
flutter run
```

It also has a web platform; in a browser it needs the local proxy described in [its README](lab4_appointment/README.md).
