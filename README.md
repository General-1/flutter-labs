# Flutter Labs

Mobile application programming labs, built with Flutter in Android Studio.

This branch holds **lab 3** only. Each lab has its own branch:
`lab1`, `lab2`, `lab3`, `lab4`.

| Lab | Folder | Description |
|-----|--------|-------------|
| 3 | [lab3_appointment](lab3_appointment/) | Lab 2 app with Cubit state management and async JSON loading |

## Running the lab

Open `lab3_appointment` in Android Studio (File → Open), or from a terminal:

```bash
cd lab3_appointment
flutter pub get
flutter run
```

It also has a web platform: `flutter run -d chrome`.
