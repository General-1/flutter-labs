# Flutter Labs

Mobile application programming labs, built with Flutter in Android Studio.

This branch holds **lab 1** only. Each lab has its own branch:
`lab1`, `lab2`, `lab3`, `lab4`.

| Lab | Folder | Description |
|-----|--------|-------------|
| 1 | [lab1_imc](lab1_imc/) | BMI (IMC) calculator |

## Running the lab

Open `lab1_imc` in Android Studio (File → Open), or from a terminal:

```bash
cd lab1_imc
flutter pub get
flutter run
```
